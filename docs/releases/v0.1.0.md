Personal desktop proxy client for one self-hosted server: **Hysteria 2** (primary) with automatic failover to **VLESS + REALITY + XTLS Vision** (fallback), built on a pinned, checksum-verified sing-box 1.14.3.

## Downloads
| Platform | File |
|---|---|
| macOS (Apple Silicon) | `Lynnk_0.1.0_aarch64.dmg` |
| Windows 10/11 (x64) | `Lynnk_0.1.0_x64-setup.exe` |

`SHA256SUMS.txt` lists the checksums.

## Install
- **macOS:** open the `.dmg`, drag Lynnk to Applications. The app is **unsigned**: the first time, System Settings → Privacy & Security → **Open Anyway**.
- **Windows:** run the setup (per-user install, no admin needed). It is **unsigned**: if SmartScreen warns, More info → Run anyway.
- **TUN mode** needs a one-time privileged helper install from Settings → Helper (macOS administrator password / Windows UAC). After upgrading, use **Reinstall helper** when the app offers it.

## Modes
- **System proxy:** covers only apps that use the system proxy. DNS lookups and IPv6 of other apps can bypass it, and there is no kill switch.
- **TUN:** whole device. IPv6 is captured and rejected, DNS goes through the tunnel, and a kill switch blocks traffic while the proxy core restarts after a crash.

## Test status
- **macOS:** real-system tests passed: helper, TUN, kill switch, system proxy, DNS / IPv6 leaks, failover, lifecycle, real-server harness.
- **Windows 11 (26H2):** three test rounds passed the main paths: install / upgrade / uninstall, system proxy, helper service, TUN, DNS / IPv6 leaks, kill switch, crash recovery, restore reporting, network change, sleep, reboot.
- **Not yet verified on Windows:** the fixes made after round 3 (TUN firewall-rule cleanup, recovery after a helper crash, failover return, Task Manager startup listing) and the new tray icons.

## Known limitations
- Unsigned builds (Gatekeeper / SmartScreen prompts).
- No OS notifications; status and failover show in the tray popover.
- On Windows, failover in TUN mode could not be tested with a firewall rule.

## If networking looks broken
Quit Lynnk, then run the app with `--restore-networking`:
- **macOS:** `/Applications/Lynnk.app/Contents/MacOS/edge-app --restore-networking`
- **Windows:** `%LOCALAPPDATA%\Lynnk\edge-app.exe --restore-networking`

Exit code 0 means fully restored. Further steps are in `docs/TESTING.md` §3.R.
